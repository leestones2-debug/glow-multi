# 클릭만 하면 되는 설정 (2단계)

## ① Mac Studio (회사)

1. Safari에서 아래 주소 열기 → **MacStudio-설정.command** 다운로드  
   https://github.com/leestones2-debug/glow-multi/raw/cursor/mac-studio-remote-setup-b168/mac-remote-setup/MacStudio-%EC%84%A4%EC%A0%95.command

2. **더블클릭** → **시작** 클릭
3. Mac Studio **비밀번호** 입력
4. Tailscale 창에서 **로그인** 클릭 (Google/Apple 등)

끝.

---

## ② 맥북 (집)

1. Safari에서 아래 주소 열기 → **맥북-연결.command** 다운로드  
   https://github.com/leestones2-debug/glow-multi/raw/cursor/mac-studio-remote-setup-b168/mac-remote-setup/%EB%A7%A5%EB%B6%81-%EC%97%B0%EA%B2%B0.command

2. **더블클릭** → **시작** 클릭
3. Tailscale **로그인** (처음만, Mac Studio와 **같은 계정**)
4. Mac Studio **비밀번호** 1번 입력
5. Mac Studio **화면이 자동으로 열림**

끝.

---

## 클릭 요약

| 순서 | 기기 | 클릭 |
|------|------|------|
| 1 | Mac Studio | `MacStudio-설정.command` 더블클릭 |
| 2 | Mac Studio | 시작 → 비밀번호 → Tailscale 로그인 |
| 3 | 맥북 | `맥북-연결.command` 더블클릭 |
| 4 | 맥북 | 시작 → Tailscale 로그인 → Mac Studio 비밀번호 |

---
